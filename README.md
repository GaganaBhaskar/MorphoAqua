# Stage 1A — Basic Hover Dynamics

## MorphoAqua

**Project:** Physics-Based Simulation and Control of a Morphing Aerial-Aquatic Robot

---

## Objective

Stage 1A establishes the fundamental flight dynamics model of MorphoAqua.

The primary objective is to determine the thrust required for the simulated robot to counteract gravity and maintain a hover condition.

This stage provides the physical baseline for the closed-loop flight-control stages that follow.

---

## System Parameters

| Parameter | Value |
|---|---:|
| Robot mass | 1.50 kg |
| Gravitational acceleration | 9.81 m/s² |
| Number of rotors | 4 |

The gravitational force acting on the robot is:

\[
W = mg
\]

For a mass of 1.50 kg:

\[
W = 1.50 \times 9.81
\]

\[
W = 14.715\;N
\]

Therefore, the total thrust required for ideal hover is:

\[
T_{total} = 14.715\;N
\]

Assuming equal thrust distribution between four rotors:

\[
T_{rotor} = \frac{14.715}{4}
\]

\[
T_{rotor} = 3.679\;N
\]

---

## Rotor Model

The simplified rotor thrust model is based on:

\[
T_i = K_f\omega_i^2
\]

where:

- \(T_i\) is the thrust generated by rotor \(i\)
- \(K_f\) is the thrust coefficient
- \(\omega_i\) is the rotor angular velocity

The corresponding rotor speed is converted into revolutions per minute (RPM) for reporting.

---

## Hover Simulation

The simulation evaluates the robot under an equal-thrust hover condition.

The expected physical condition is:

\[
T_{total} - mg = 0
\]

Therefore:

\[
a_z = 0
\]

and the robot should remain stationary when the hover thrust is maintained.

## Interpretation

The simulation establishes the nominal thrust required for MorphoAqua to counteract its gravitational weight.

The calculated total thrust is equal to the gravitational force:

\[
T_{total} = mg
\]

This represents the ideal hover operating point used as the baseline for subsequent controller development.

---

## Important Simulation Limitation

The values reported in this stage are **numerical simulation results**, not measurements obtained from a physical robot.

The model uses assumed physical parameters and a simplified rotor thrust relationship.

Real-world flight performance would additionally depend on factors such as:

- Propeller characteristics
- Motor efficiency
- Battery voltage
- ESC response
- Aerodynamic effects
- Vehicle mass distribution
- Environmental disturbances
- Sensor and actuator limitations

These effects will be considered progressively in later stages.
